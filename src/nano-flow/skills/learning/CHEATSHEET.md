# 速查卡

速查卡给一个领域的知识骨架：有哪些概念、各自管什么、彼此怎么排。读者扫一遍能说出「有什么、怎么选」；实现细节与来龙去脉由知识笔记承接（单点问题见 [NOTE.md](NOTE.md)）。

材料不限书、工具文档、SOP 或自有笔记，链路固定为：取材 → 分区 → 条目 → 版面 → 出图。

## 取材

- 收录「体系 × 常用」：概念定义、分类与边界、选型对照、关键取值;
- 判据：读者知道要查什么，卡里就有答案；不知道先查哪块，看区名能定位;
- 实现细节（分步操作、参数含义、推导、命令选项）进知识笔记，卡里最多留一句提示;
- 篇幅按源材料长度的 3%，是上限不是配额;

## 分区

- 区（`##`）是体系的一层骨架，按概念族与边界切，不照抄材料章节;
- 子区（`###`）是区里最细的知识点，一个子区只讲一件事;
- 区内按本领域的自然论述推进：先立骨架（是什么、有哪些），再按需展开分类、对照或流程；同一张卡保持同一种推进节奏，第二遍查找位置可预期;
- 区名用领域短名词，能直接被搜到;

## 条目

- 一行一条 `标签: 解释;`，标签是短名词，解释是最短完整句;
- 每条 ≤89 字，只讲「是什么、管什么、怎么选」；写不下说明混了两件事，拆开;
- 面向硕士水平初学者：术语直接用，首次出现用半句交代它在体系里的位置，原理留到笔记;
- 对照用表格，关系与流转用 `mermaid`，示例用最短代码块;
- 标点、术语与风格细则见 [SKILL.md](SKILL.md) 第 3 节;

## 版面

- A4 横向、固定 5 栏、默认 5pt；页数优先，字号在 4~6pt 内调;
- 多页时末页可留白；不为凑页均分内容。

## 出图

- Markdown 是源，`page-N.png` 拼成的 `cheatsheet.png` 是派生物。

```bash
node scripts/render-sheet.mjs <主题>.cheatsheet.md --out <主题>.cheatsheet/ --source <源材料> --fit 2
```

- 末列被裁时：排版器按元素高度排栏、不计外边距，在源文件开头加一行校准，把节间距改成内边距。

```html
<style>
  .sec {
    margin: 0 !important;
    padding-bottom: 2px;
  }
  .sec .st {
    margin: 0 !important;
    padding: 1px 0;
  }
</style>
```

## 模板

```markdown
---
id: {稳定 UUID}
anki: false
title: {主题} Cheat Sheet
subtitle: {版本 / 平台}
source: {来源}
---

## {概念族}

### {最细知识点}

- <术语>: <它是什么、管什么>;

{按本领域补：分类、对照、流程、最小示例，取需要的}
```
