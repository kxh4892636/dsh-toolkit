# 速查卡

一张随手查的参照卡：读者已经知道要找什么，来查怎么用、选哪个。不是教程，也不是知识笔记；单点问题用 [NOTE.md](NOTE.md)。

## 结构

- 按读者的问题分区（`##`），不跟书的章序；一张卡 3~6 个区；
- 区放不下一栏时用 `###` 切子区，层级到这一层为止；
- 先写读者要做的决定（何时 X → 做 Y），再写取值、信号与命令；
- 区名用读者的问法：「怎么排错」而不是「第 7 章」；
- 同一事实只落一处，其他位置写指向。

## 内容

- 只收高频 × 难记：查了就能用的判定条件、具体取值、命令、对比结论；
- 条目沿用 [SKILL.md](SKILL.md) 第 3 节：一行一条 `标签: 解释;`、半角标点、`;` 结尾、只写事实与机制；
- 能给图就不写字：时序、状态流转、分层模型用 `mermaid`，多维对比用表格；
- 篇幅按源材料的 3% 取，这是上限不是配额;

## 版式与渲染

- A4 横向、固定 5 栏、默认 5pt；页数优先，字号在 4~6pt 内调；
- 多页时末页可留白；不为凑页均分内容；
- 产物是 `page-N.png` 与拼接图 `sheet.png`；Markdown 是源，PNG 是派生物。

```bash
node scripts/render-sheet.mjs <主题>.cheatsheet.md --out <主题>.cheatsheet/ --source <源材料> --fit 2
```

## 首部

开头三行写清卡名、范围与来源：

```yaml
---
title: Python Cheat Sheet
subtitle: 3.12 / macOS
source: docs.python.org/3
---
```
