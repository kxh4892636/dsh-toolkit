# Anki

卡片以 [NOTE.md](NOTE.md) 产出的知识笔记为来源，`id` / `anki` 取自笔记 frontmatter，这里只读。

## 1. 制卡准备

从工作区事实和用户输入进行默认推断, 卡点进行询问：

- 制卡的笔记目录，缺省为本轮产出的笔记目录；
- anki 卡片/牌组配置;
- 使用 `nnf anki` / AnkiConnect 进行去重;

## 2. 解析材料

默认每份笔记一张卡, 跳过 `anki: false` 的笔记; 子牌组名称取文件名, 卡片中的牌组名去数字前缀与 `.md`, 复用 uuid frontmatter：

| 配置           | 默认值                                                      |
| -------------- | ----------------------------------------------------------- |
| 根牌组         | `<topic>`;                                                  |
| 笔记类型、字段 | `基础`；`正面` / `背面`                                     |
| 正面           | `根牌组-章节名-知识点`                                      |
| 背面           | `<a href="https://wiki.kongxiaohan.cn/<uuid>">跳转wiki</a>` |

## 3. 预览确认

预览确认录入的 anki 卡片;
每候选一行，展示唯一序号、来源、完整牌组路径及全部实际字段；列明排除及原因、假设、未验证项和冲突。

## 4. 创建

读取 `/nano-flow-cli skill` 通过 `nnf anki` 创建 anki 牌组/卡片;
