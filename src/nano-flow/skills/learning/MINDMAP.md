# 导图笔记

导图笔记是一张导航图：一张图覆盖一个领域，节点是标题，父子关系是标题层级；读者点节点看概述与引用。导图只给结构，详细实现由知识笔记承接；卡片落在知识笔记，frontmatter 写 `anki: false`。

## 节点

`<Mindmap>` 标签内是普通 markdown。每个标题以数字编号开头，编号就是节点 id。构建期检查：

- 根唯一：有且只有一个 `#`；
- 标题有编号；
- 层级不跳级；
- 编号在同一张图里唯一；
- 节点引用指向已存在的编号。

任一不满足就报错。构建期只检查上述五项；编号按父前缀续写（`1` → `1.1` → `1.1.1`），方便阅读。

## 概述与引用

概述写在标题下：不带链接的普通段落直接显示；列表要放进 `>` 引用块才生效。浮窗逐行显示纯文本，代码块留在正文。

引用是链接，写在 `>` 引用块或普通段落里，一条一行：

- `doc:<文档id>`：打开 `/<id>` 短链，新标签页；跳转只认 `doc:` 后的 id，相对路径只供阅读；构建期只检查后缀，目标是否存在靠点击验证。写前核对目标文档的 `id`。
- `#<编号>`：关闭浮窗，跳到本图节点；编号不存在时构建报错。

## 模板

```markdown
---
id: <uuid>
anki: false
---

# <领域>

一句话说明这张图讲什么。

<Mindmap>

# 1 <领域>

一句话概述;

## 1.1 <子主题>

一句话概述;

> - [<标签>](<路径>.md) doc:<文档id>
> - [<标签>](#1.1.1)

### 1.1.1 <子子主题>

一句话概述;

</Mindmap>
```
