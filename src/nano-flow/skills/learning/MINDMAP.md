# Mindmap

导图笔记是一张导航图：一张图覆盖一个主题，节点是标题，父子关系即标题层级；读者点节点看概述与引用，导图只读。材料有清晰层级、读者先需要整体结构时写导图，与正文笔记并存，同一解释只写一处。

## 排节点

`<Mindmap>` 标签内是普通 markdown；每个标题以数字编号开头，编号就是节点 id。构建期检查：

- 根唯一：必须有且只有一个 `#`；
- 标题有编号；
- 层级不跳级；
- 编号在同一张图里唯一；
- 节点引用指向已存在的编号。

任一不满足就报错。编号按父前缀续写（`1` → `1.1` → `1.1.1`）方便阅读，连续性不校验。

## 概述与引用

标题下的普通段落是概述，浮窗逐行显示纯文本；
引用是链接，写在 `>` 引用块里，一条一行；普通段落里的链接同样算引用。

- `doc:<文档id>`：打开 `/<id>` 短链，新标签页；解析只认 `doc:` 后的 id，链接路径不参与跳转；构建期只检查后缀存在，目标是否存在靠点击验证，写前核对目标文档的 `id`。
- `#<编号>`：关闭浮窗，跳到本图节点；编号不存在时构建报错。

## 模板

```markdown
---
id: <uuid>
anki: false
---

# <主题>

一句话说明这张图讲什么。

<Mindmap>

# 1 <主题>

## 1.1 <子主题>

使用列表格式的简单概述

> - [<标签>](<路径>.md) doc:<文档id>
> - [<标签>](#1.1.1)

</Mindmap>
```
