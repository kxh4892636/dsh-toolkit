# Learning

把一份学习材料整理成 Markdown 知识笔记；格式与模板见 [NOTE.md](NOTE.md)，需要 Anki 卡片时另读 [ANKI.md](ANKI.md)，需要一张通览领域知识体系的速查卡时另读 [CHEATSHEET.md](CHEATSHEET.md)。

## 1. 覆盖账本

完整读取材料，记录有意义的知识点，合并语义重复并保留来源位置；为每项标出产出位置或排除理由。材料外的未知知识点可联网检索补充。

## 2. 组织目录

按概念体系划分笔记顶级目录，速查卡可选，知识笔记平铺：

```
{笔记顶级目录}
├── 000-cheatsheet.md      # 速查卡源
├── 000-cheatsheet.png     # 速查卡成品，由源渲染
├── {NOTE-1}.md            # 知识笔记
└── {NOTE-2}.md            # 知识笔记
```

## 3. 写作规范

- 一行一条 `标签: 解释;`：标签用短名词，解释用一句完整短句；只写事实、机制与具体取值；语言简单直白，面向硕士水平读者；术语首次出现时用半句交代它在体系里的位置；
- 正文标点用半角，条目以 `;` 结尾、不写句号；
- 条目字数（知识笔记）：均值 33.3，P50 29.0，P90 56.0，P95 69.0；超 60 字只占 7.9%，留给标识符串与链接枚举；速查卡条目上限见 [CHEATSHEET.md](CHEATSHEET.md);
- 每节条数：均值 3.5，P50 3.0，P90 6.0；超 8 条只占 2.2%，超过 6 条考虑拆成两个小节；
- 优先代码块、表格、公式、图示；
- 状态流转、时序、流程图用 mermaid 代码块（语言标记 `mermaid`），简单链路用列表或表格。

frontmatter 写 `id` 与 `anki`：`id` 为稳定 UUID；`anki` 缺省 true，`anki: false` 不制卡。

## 4. 收尾

每次调用都跑一次校验脚本并进行修正，覆盖本轮全部产出目录，实测值对照第 3 节的参考值：

```bash
python3 scripts/note-metrics.py <笔记目录>... [--detail] [--json] [--exclude <路径子串>]
```
