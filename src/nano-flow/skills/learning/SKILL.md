# Learning

整理笔记执行下方流程；制作 Anki 卡片时读取 [ANKI.md](ANKI.md)，可独立执行。

## 1. 覆盖账本

完整读取材料，记录有意义的知识点，合并语义重复并保留全部来源位置；为每项记录产出位置或明确的排除理由。

## 2. 组织笔记

按概念体系划分笔记顶级目录，顶级目录下平铺思维导图或可独立学习的知识笔记：

```
{笔记顶级目录}
├── MINDMAP.md        # 思维导图笔记
├── {NOTE-1}.md       # 知识笔记
└── {NOTE-2}.md       # 知识笔记
```

## 3. 写入笔记

### 通用规则

- 笔记风格使用 **费曼技巧**, 笔记格式使用 **电报体**，笔记内容使用简单清晰的**短句**；
  - 笔记语言像电报: 一行一条 `标签: 解释;`，标签用短名词，解释是最短完整句；只写事实、机制与具体取值，不用「我们」「你」「其实」「因此」这类口语与过渡词；正文标点用半角，条目以 `;` 结尾、不写句号；
  - 条目字数: 均值 33.3 字，P50 为 29.0 字，P90 为 56.0 字，P95 为 69.0 字；超 60 字的只占 7.9%，只留给标识符串和链接枚举；
  - 每节条数: 均值 3.5 条，P50 为 3.0 条，P90 为 6.0 条；超 8 条的只占 2.2%，超过 6 条就考虑拆成两个 HX；

frontmatter 使用 `id` 与 `anki` 两个字段：`id` 为稳定 UUID；`anki` 缺省为 true，标记 `anki: false` 的笔记不制作卡片。

### 思维导图

- 思维导图笔记用于系统梳理一个领域的知识体系；
- 笔记涉及该领域的概念分层结构，每个概念的一句话概述，不同概念之间的引用关系（节点和知识笔记的引用）；
- 无须阐述每个概念的详细实现内容，这个有知识笔记承接；

导图笔记的格式与校验见 [MINDMAP.md](MINDMAP.md)。

### 知识笔记

- 知识笔记用于解决一个领域中的具体问题；
- 笔记包括该问题涉及的若干概念的详细实现内容，以及概念之前的编排关系；

导图笔记的格式与校验见 [MINDMAP.md](MINDMAP.md)。

写入后逐项核对覆盖账本：范围内知识点均能定位到产出且无遗漏，UUID 无冲突、相对链接有效，并通过适用的文档格式与构建校验时完成。
