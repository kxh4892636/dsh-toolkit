# Learning

把一份学习材料整理成 Markdown 笔记；需要 Anki 卡片时另读 [ANKI.md](ANKI.md)。

## 1. 覆盖账本

完整读取材料，记录有意义的知识点，合并语义重复并保留来源位置；为每项标出产出位置或排除理由。

## 2. 组织目录

按概念体系划分笔记顶级目录；每个顶级目录放一份导图笔记，知识笔记平铺：

```
{笔记顶级目录}
├── MINDMAP.md        # 导图笔记
├── {NOTE-1}.md       # 知识笔记
└── {NOTE-2}.md       # 知识笔记
```

## 3. 选类型

- 先看领域全貌、梳理概念关系：写**导图笔记**，规则与模板见 [MINDMAP.md](MINDMAP.md)；
- 解决一个具体问题、需要完整讲解：写**知识笔记**，规则与模板见 [NOTE.md](NOTE.md)。

两类并存；同一解释只写一处，导图节点引用知识笔记。

## 4. 写作规范

- 使用费曼技巧、电报体、短句；
- 一行一条 `标签: 解释;`：标签用短名词，解释用最短完整句；只写事实、机制与具体取值；
- 正文标点用半角，条目以 `;` 结尾、不写句号；
- 条目字数：均值 33.3，P50 29.0，P90 56.0，P95 69.0；超 60 字只占 7.9%，留给标识符串与链接枚举；
- 每节条数：均值 3.5，P50 3.0，P90 6.0；超 8 条只占 2.2%，超过 6 条考虑拆成两个小节；
- 优先代码块、表格、公式、图示。

frontmatter 写 `id` 与 `anki`：`id` 为稳定 UUID；`anki` 缺省 true，`anki: false` 不制卡。

```bash
python3 scripts/note-metrics.py <笔记目录>... [--detail] [--json] [--exclude <路径子串>]
```

## 5. 收尾

逐项核对账本：知识点都有产出或排除理由；UUID 无冲突；相对链接可达；文档格式与构建校验通过。
